## Usage

Copy the pattern folder's `template.py` into a new file per problem, fill in the header, solve, then check it off in the table above.

```
cp 01-arrays-hashing/template.py 01-arrays-hashing/two_sum.py
```

Save progress with:

```
./save.sh "two sum"
```
